# Портфолио сайты — Елдарын Төлеген

Файлдар:
- `index.html` — жариялық бет (жұмыс берушілерге жіберетін сілтеме)
- `admin.html` — админ панелі (мазмұнды өзгертуге арналған, `/admin` арқылы қол жеткізіледі)
- `data.js` — барлық мазмұн осында сақталады
- `style.css` — дизайн

## Деплой (Vercel немесе Netlify)

Бұл — таза статикалық сайт (backend жоқ), сондықтан build қадамы қажет емес.

**Vercel:**
1. Осы `portfolio-site` папкасын GitHub репозиторийіне жүктеңіз (немесе Vercel CLI арқылы: `vercel` командасын осы папкада іске қосыңыз).
2. Vercel-де "New Project" → репозиторийді таңдаңыз → Framework Preset: **Other** → Deploy.
3. Дайын: `https://сіздің-жоба.vercel.app` сілтеңізі шығады, `/admin.html` — админ бетіңіз.

**Netlify:**
1. netlify.com → "Add new site" → "Deploy manually" → осы папканы сүйреп апарыңыз (drag-and-drop).
2. Немесе GitHub-пен байланыстырып, Build command бос қалдырыңыз, Publish directory: `/`.

## Қалай жұмыс істейді

- **Жұмыс берушіге арналған сілтеме:** `https://сіздің-домен.com/` — толық портфолио, жоғарыдан "PDF жүктеп алу" батырмасы (браузердің "Басып шығару" терезесі арқылы PDF ретінде сақтауға болады).
- **Сіздің админ сілтеңіз:** `https://сіздің-домен.com/admin.html` — құпия сөз сұрайды (әдепкі: `yeldaryn2026`, оны `admin.html` файлындағы `ADMIN_PASSWORD` жолынан өзгерте аласыз).

### Маңызды шектеу

Бұл — backend-сіз, таза статикалық сайт. Сондықтан админ панеліндегі өзгерістер алдымен **тек сол құрылғының браузерінде ғана** сақталады (localStorage). Оны барлық қонақтарға көрсету үшін:

1. Админ панелінде мазмұнды өзгертіп, **"Сақтау"** басыңыз (алдын ала қарау үшін).
2. Дайын болған соң **"data.js жүктеп алу"** батырмасын басып, жаңа `data.js` файлын жүктеп алыңыз.
3. Осы файлды жобаңыздағы ескі `data.js` файлының орнына қойып, GitHub-қа push жасаңыз (немесе Netlify-ге қайта drag-and-drop жасаңыз) — Vercel/Netlify автоматты қайта деплой жасайды.

Егер болашақта админ панеліндегі өзгерістер **бірден, файл ауыстырмай-ақ** барлық қонақтарға көрінуін қаласаңыз, буманы дерекқормен (мысалы Supabase немесе Firebase) байланыстыру керек — бұл қосымша қадам, қаласаңыз кейін қосып берейін.

## Кеңес

- Логотип/сурет қосқыңыз келсе, `index.html`-ге сурет тегін қосып, `style.css`-те безендіруге болады.
- Құпия сөзді ешқашан нағыз құпия ретінде қарамаңыз — ол тек кездейсоқ қонақтарды тоқтату үшін, себебі HTML файлдың ішінде ашық көрінеді.
